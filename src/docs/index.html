Conventions

Everything below is relative to /api/v1 unless stated otherwise.

Requests and responses are JSON, UTF-8. The request body limit is 256 kb. Every resource is keyed by a UUID; polls are additionally addressable by a short public slug, which is what appears in share links.

Successful responses are wrapped in a named key rather than returned bare — { "poll": … }, { "polls": [ … ] } — so a response can grow extra top-level fields without breaking clients.

Timestamps are ISO-8601 in UTC. List endpoints take limit (1–100, default 20) and offset (default 0).

Authentication

JWT, accepted two ways.

Sign-in endpoints return a token and set it as a signed, httpOnly cookie named ph_at. Browser clients need nothing further — the cookie travels automatically. Non-browser clients send the header:

Authorization: Bearer <token>

Access tokens live for 15 minutes. Requests are authenticated in one of three modes:

ModeBehaviour
publicNo token read. Open to anyone.
optionalA valid token is used if present; a missing or invalid one is not an error. Used on all respondent-facing routes.
creatorValid token required, else 401.
adminValid token and role: "admin", else 403.
Respondent routes never hard-require a login. Whether an account is needed is decided per poll by its identityMode, not by the route. A public poll must not 401 someone who simply isn't signed in.

Errors

One shape for every failure.

Error envelope
{
  "error": {
    "code": "not_found",
    "message": "Poll not found",
    "details": null
  }
}
Validation failure (422)
{
  "error": {
    "code": "validation_failed",
    "message": "Request validation failed",
    "details": [
      { "path": "questions.0.options",
        "message": "single_choice questions need at least 2 options" }
    ]
  }
}
StatusCodeMeaning
400bad_requestMalformed or semantically invalid request.
400invalid_jsonBody was not parseable JSON.
401unauthorizedMissing, invalid, or expired token.
403forbiddenAuthenticated, but not permitted — wrong role or not the owner.
404not_foundNo such resource. Also returned for draft polls fetched by slug, so drafts stay unguessable.
409conflictState collision — most often a duplicate response caught by dedup.
410goneExisted, no longer available. Archived polls.
422validation_failedSchema validation failed. details lists each offending path.
429rate_limitedLimit exceeded. See Retry-After.
500internal_errorUnhandled fault. Internals are never leaked in production.

Rate limits

Keyed on the resolved client IP. Two tiers.

TierBudgetApplies to
auth10 / minSignup, login, verification, password reset, OAuth.
write60 / minPoll mutations, response submission, invites, notifications, moderation.
read300 / minAll GET endpoints.
upload20 / minUpload signatures.
vote (durable)30 / hour
per poll per IP		Response submission. Backed by Postgres, so it survives a restart.

Every limited response carries X-RateLimit-Remaining. A 429 also carries Retry-After, in seconds.

The first four tiers are in-process. They are global only because v1 runs as a single Node process — the moment a second instance exists, only the durable vote tier still holds across the fleet.

Auth

Accounts, sessions, and Google sign-in.

POST/auth/signup public

Creates a creator account and signs it in immediately. A verification email is sent, but the account is usable before it is confirmed.

Request
{
  "email": "ada@example.com",
  "password": "at-least-8-chars",
  "name": "Ada Lovelace"
}
Response 201
{
  "user": {
    "id": "uuid", "email": "ada@example.com",
    "name": "Ada Lovelace", "role": "creator",
    "verified": false
  },
  "token": "eyJhbGciOi…"
}

Errors — 409 email already registered · 422 validation.

POST/auth/login public

Exchanges credentials for a token and sets the ph_at cookie.

Request
{
  "email": "ada@example.com",
  "password": "…"
}
Response 200
{
  "user": { … },
  "token": "eyJhbGciOi…"
}

Errors — 401 bad credentials · 403 account suspended.

POST/auth/logout public

Clears the auth cookie. Returns 204. Safe to call unauthenticated — a bearer token held by the client must be discarded client-side.

GET/auth/me creator

The signed-in user.

Response 200
{ "user": { "id": "uuid", "email": "…", "name": "…", "role": "creator", "verified": true } }
POST/auth/verify-email public

Confirms an address using the token from the verification email.

Request
{ "token": "…" }
Response 200
{ "user": { …, "verified": true } }
POST/auth/password/request-reset public

Starts a password reset.

Request
{ "email": "ada@example.com" }
Response 202
{
  "message": "If that address has an account,
              a reset link is on its way"
}

The response is identical whether or not the address exists — this endpoint is not an account-enumeration oracle.

POST/auth/password/reset public
Request
{
  "token": "…",
  "password": "at-least-8-chars"
}
Response 200
{ "user": { … } }
GET/auth/google public

302 to Google's consent screen. Sets a signed state cookie the callback checks, which is what makes the flow CSRF-resistant. Navigate the browser here — this is not an XHR endpoint.

400 if Google sign-in is not configured on this deployment.

GET/auth/google/callback public

Google redirects here with ?code=&state=. Exchanges the code server-side, then creates or links the account by sub, falling back to email. Google-verified addresses skip email verification entirely.

Response 200
{ "user": { … }, "token": "eyJhbGciOi…" }

Polls

A poll is either a Quick Vote (exactly one question) or a Survey (up to 50).

GET/polls/public public

Published polls with visibility: "public". Query: limit, offset.

Response 200
{ "polls": [ { "id": "uuid", "type": "vote", "title": "…", "slug": "a1b2c3", "status": "published", … } ] }
GET /polls/slug/:slug optional

The respondent view — the endpoint the public poll page is built on. Option counts are omitted unless this viewer is allowed to see results, decided by the poll's resultsMode.

Response 200
{
  "poll": { "id": "uuid", "title": "…", "type": "vote", "identityMode": "anonymous", … },
  "questions": [
    { "id": "uuid", "position": 0, "type": "single_choice", "prompt": "…", "required": true,
      "options": [ { "id": "uuid", "label": "Yaba", "count": 12 } ] }
  ],
  "state": { "notYetOpen": false, "isClosed": false, "acceptingResponses": true },
  "resultsVisible": true
}

Errors — 404 unknown slug, or the poll is a draft · 410 archived.

GET /polls/:id/qr.svg public

QR code for the poll's share link, as image/svg+xml. Cached for 24 hours. Embed it directly with <img src="…/qr.svg">.

POST/polls creator

Creates a poll with its questions and options in one transaction. Created as draft — it accepts no responses until published.

Request
{
  "type": "vote",
  "title": "Where should we host the meetup?",
  "description": "Pick one venue.",
  "visibility": "unlisted",        // public | unlisted | private
  "identityMode": "anonymous",     // anonymous | name_required | account_required
  "dedupMode": "cookie_device",    // none | cookie_device | ip | account | invite_code
  "resultsMode": "after_vote",     // live | after_vote | after_close | creator_only
  "coverPublicId": "pollhub/cover/xyz",
  "opensAt": "2026-08-10T09:00:00Z",
  "closesAt": "2026-08-17T09:00:00Z",
  "questions": [
    {
      "type": "single_choice",
      "prompt": "Where should we host the meetup?",
      "required": true,
      "options": [ { "label": "Yaba" }, { "label": "Lekki" }, { "label": "Ikeja" } ]
    }
  ]
}
Response 201
{ "poll": { "id": "uuid", "slug": "a1b2c3", "status": "draft", … } }

Rules enforced at validation — a vote takes exactly one question · choice questions need ≥ 2 options · non-choice questions must have none · closesAt must be after opensAt · account_required may not pair with dedupMode: "none".

GET/polls creator

Your own polls. Query: status, limit, offset.

{ "polls": [ … ] }
GET /polls/:id creator

Full poll with questions and options, owner fields included. 403 if you don't own it.

{ "poll": { … }, "questions": [ … ] }
PATCH /polls/:id creator

Settings only — every field optional. Question edits are not part of this endpoint. Nullable fields accept null to clear them.

{ "title": "…", "visibility": "public", "resultsMode": "live", "closesAt": null }
POST /polls/:id/publish creator

draft → published. Stamps publishedAt and opens the poll to responses.

POST /polls/:id/close creator

published → closed. Stops accepting responses; results stay readable. A poll with closesAt in the past is closed automatically by the scheduler.

POST /polls/:id/archive creator

Hides the poll. Fetching it by slug then returns 410.

POST /polls/:id/duplicate creator

Copies structure and settings into a fresh draft with a new slug. Responses and tallies are not copied. 201.

Responses

Vote submission and the pre-flight check that precedes it.

GET /polls/:slug/status optional

Whether this caller has already responded, evaluated under the poll's own dedup mode. Call it before rendering the form so a repeat visitor sees results instead of a ballot they can't submit.

Response 200
{ "hasResponded": false, "dedupMode": "cookie_device" }
POST /polls/:slug/responses optional

Submits a response. Answers, dedup, and tally updates commit in one transaction — a counted vote is always a stored vote.

Request
{
  "answers": [
    { "questionId": "uuid", "optionIds": ["uuid"] },        // choice
    { "questionId": "uuid", "valueText": "Great venue" },   // short_text / long_text
    { "questionId": "uuid", "valueNum": 4 }                 // rating
  ],
  "respondentName": "Ada",      // required when identityMode = name_required
  "inviteCode": "K3F9-2QMX",    // required when dedupMode = invite_code
  "turnstileToken": "…",        // when Turnstile is configured
  "fingerprint": "…"            // optional device signal
}
Response 201
{
  "responseId": "uuid",
  "responseCount": 43,
  "resultsVisible": true,
  "tallies": { "<optionId>": 12, "<optionId>": 31 }   // omitted when not visible
}

Errors — 401 poll requires an account · 403 bad or spent invite code · 409 already responded · 410 poll closed or not yet open · 422 answers don't match the questions · 429 vote limit.

Dedup is server-side. The device id lives in a signed cookie (ph_did), so it can't be edited to mint a fresh identity per vote, and raw IPs are never stored — only a peppered HMAC.

Invites

One-time codes for polls gated by dedupMode: "invite_code".

POST /polls/:id/invites creator

Issues codes. Pass emails to generate one per address and mail it out, or count to generate unassigned codes you distribute yourself. Default 10, max 500.

Request
{ "count": 50 }

// or
{ "emails": ["a@x.com", "b@x.com"] }
Response 201
{
  "codes": [
    { "code": "K3F9-2QMX", "email": "a@x.com" },
    { "code": "P7RT-4WQZ", "email": null }
  ]
}
Codes are returned in plaintext exactly once — here. Only their hash is stored, so a database leak doesn't hand out working ballots. If you lose them, reissue.
GET /polls/:id/invites creator

Issued codes with redemption state, plus totals. Codes themselves are not returned.

{
  "invites": [ { "id": "uuid", "email": "a@x.com", "usedAt": "2026-08-05T…", "createdAt": "…" } ],
  "stats":   { "issued": 50, "used": 31 }
}

Analytics

Owner-only. Every endpoint 403s for anyone but the poll's owner.

GET /polls/:id/analytics creator

Summary, response volume over time, per-question drop-off, and the option breakdown.

Response 200
{
  "summary": { "responses": 431, "completionRate": 82.4, … },
  "responsesOverTime": [ { "bucket": "2026-08-05T10:00:00Z", "count": 24 } ],
  "questions": [
    { "id": "uuid", "position": 0, "prompt": "…", "type": "single_choice",
      "answered": 431, "dropOffPct": 0 },
    { "id": "uuid", "position": 1, "prompt": "…", "type": "rating",
      "answered": 355, "dropOffPct": 17.6 }
  ],
  "options": [ { "questionId": "uuid", "optionId": "uuid", "label": "Yaba", "count": 180 } ]
}

dropOffPct is measured against the first question — the one everyone who started the survey saw. completionRate is the last question's answered count over the first's.

GET /polls/:id/export.csv creator

Every response as CSV — one row per response, one column per question. Multi-choice answers are joined with ; in a single cell. Returns text/csv as an attachment named poll-<slug>.csv.

response_id,submitted_at,respondent_name,Where should we host the meetup?
uuid,2026-08-05T10:14:02.000Z,Ada,Yaba
GET /polls/:id/questions/:questionId/answers creator

Free-text answers for one question — the open-ended replies that can't be charted.

{ "answers": [ { "responseId": "uuid", "valueText": "Great venue", "submittedAt": "…" } ] }

Uploads

POST/uploads/sign creator

Mints a short-lived Cloudinary upload signature. The client then uploads directly to Cloudinary — image bytes never pass through this server. Send the returned publicId back as coverPublicId or an option's imagePublicId.

Request
{ "kind": "cover" }
// option | cover | avatar
Response 200
{
  "upload": {
    "cloudName": "…", "apiKey": "…",
    "folder": "pollhub/cover",
    "timestamp": 1754563200,
    "signature": "…"
  }
}

Auth is required so anonymous respondents can't burn the Cloudinary credit pool. Rate limited to 20/min.

Moderation

Reporting is open to everyone; the queue is admin-only.

POST/moderation/reports optional

Flags a poll. Deliberately open to unauthenticated callers — a respondent who hits an abusive poll from a shared link has no account and must still be able to report it. The reporter is recorded when signed in, null otherwise.

Request
{
  "pollId": "uuid",
  "reason": "Spam / abusive content"
}
Response 201
{ "report": { "id": "uuid", "created_at": "…" } }
GET/moderation/reports admin

The open queue, oldest first, capped at 100.

{ "reports": [
  { "id": "uuid", "reason": "…", "status": "open", "created_at": "…",
    "poll_id": "uuid", "title": "…", "slug": "a1b2c3", "poll_status": "published" }
] }
POST /moderation/reports/:id/uphold admin

Upholds the report: archives the poll and evicts its tally mirror, so live results stop broadcasting immediately.

{ "ok": true, "pollId": "uuid" }

404 if the report doesn't exist or was already resolved.

POST /moderation/reports/:id/dismiss admin

Closes the report without touching the poll. { "ok": true }

POST /moderation/users/:id/suspend admin

Suspends a user. They can no longer sign in. { "ok": true }

WebSocket — live results

Same host, same port as the REST API.

WS/ws public 
wss://pollhub-api.onrender.com/ws

Connect, then subscribe to a poll. You'll get a snapshot immediately, then a delta on every counted vote.

Client → server
{ "type": "subscribe", "pollId": "uuid" }
{ "type": "ping" }
Server → client
{ "type": "snapshot", "pollId": "uuid",
  "tallies": { "<optionId>": 12 } }

{ "type": "tally", "pollId": "uuid",
  "tallies": { "<optionId>": 13 } }

{ "type": "status", "pollId": "uuid",
  "status": "closed" }

{ "type": "pong" }
{ "type": "error", "message": "…" }

Subscription is refused when resultsMode is creator_only, or when it is after_close and the poll is still open. That check runs here as well as in the REST layer — otherwise a creator-only poll would leak its live tally over the socket.

The server pings every 30 seconds and terminates sockets that stop answering. Clients should reconnect with backoff and re-subscribe; the snapshot on subscribe means no state is lost across a reconnect.

Poll lifecycle

draft ──publish──> published ──close──> closed
  │                    │                  │
  └──────────────── archive ──────────────┘  →  archived (410 to respondents)
StatusAccepts responsesPublic by slug
draftNoNo — returns 404, so drafts stay unguessable
publishedYes, within the open windowYes
closedNoYes, results readable
archivedNoNo — returns 410

A poll with opensAt in the future reports state.notYetOpen and rejects responses. One with closesAt in the past is closed by the background scheduler without needing an explicit call.
